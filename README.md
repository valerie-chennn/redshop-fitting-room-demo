# REDroom — AI Fitting Room Concept

An interactive product concept that connects fashion inspiration, personalized virtual try-on, outfit generation, saved looks and item-level purchase decisions.

Live demo: https://valerie-chennn.github.io/redshop-fitting-room-demo/

## Run locally

Serve the `dist` directory with any static server. For example:

```bash
python3 -m http.server 4177 --directory dist
```

Then open `http://127.0.0.1:4177`.

## Experience

`outfit discovery → outfit details → product details → single-item try-on → personalized full look → saved looks → purchase list`

All products, inventory, prices, people, and imagery are illustrative.
